PYTHON ENVIRONMENT (PYTHON_VERSION) - rmenv, mkenv, install

ENVIRONMENT
  mkenv             Create .venv (uv, PYTHON_VERSION) and .envrc
  install           Install torch cu130 + requirements, fixenv, then installsage
  rmenv             Delete .envrc, .venv, uv.lock and exit the shell
  fixenv            Re-add 'unset LD_LIBRARY_PATH' to .envrc, direnv allow
  installsage       Build + install SageAttention 2 (the 'sage2' mode, ~mins)
  checksage         Print the attention modes wgp will actually offer

SERVICE (wan-gpt.service, port 7860)
  run               Start the wan-gpt service
  stop              Stop the wan-gpt service
  restart           Restart the wan-gpt service
  sstatus           Show service status
  slog              Last 50 log lines
  slogf             Follow the log
  runf              Run wgp.py in this shell instead (for debugging startup)
